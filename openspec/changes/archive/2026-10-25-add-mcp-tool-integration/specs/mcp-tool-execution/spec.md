# Spec Delta

## Purpose

定义宿主如何在命中技能允许的最小工具范围内执行模型提出的 MCP 调用，并以参数校验、独立授权、持久化配额、结果数据边界和班级审计约束每次动作，使工具异常不会破坏原有问答主路径。

## ADDED Requirements

### Requirement: 最小候选集与模型决策

一次提问 MUST 继续使用既有确定性词法规则选择至多一个技能。只有该技能声明的、本班已连接且存在于已确认发现快照的 MCP 工具 MUST 能作为候选；声明的名称、说明和参数结构 MUST 来源于该快照，MUST NOT 把全班工具清单一并交给模型。模型 MUST 决定调用哪个候选及填写参数，宿主 MUST NOT 通过固定的 `query=问题` 自动执行全部声明工具。无命中技能或无 MCP 引用时 MUST 不发起 MCP 工具决策和调用；`knowledge_search` MUST 保留现有检索语义而不是隐式转成远端工具。

#### Scenario: 候选集不扩权

- **WHEN** 命中技能只包含 `formula_hint@campus-tools`，本班另有其他工具
- **THEN** 模型 MUST 只能看到该引用对应的工具声明
- **AND** 宿主 MUST NOT 执行模型提出的其他工具

#### Scenario: 模型不要求调用

- **WHEN** 模型认为无需工具并未提出调用
- **THEN** 宿主 MUST 不发出 `tools/call`
- **AND** MUST 继续最终答案生成，MUST NOT 伪造成功调用记录

### Requirement: 每次调用授权与同源参数校验

执行每次调用前，宿主 MUST 核对当前班级、命中技能的允许集合、服务器连接及批准快照仍有效，并使用产生工具声明的同一输入结构校验参数。参数 MUST 是有界 JSON 对象，不能是可执行代码；输入结构 MUST 禁止远程引用加载。未连接、缺失/已删除、跨班、候选集外或快照失效 MUST 为 `denied`；参数无效 MUST 为 `error`；两者 MUST 不发远端请求。获得授权的调用 MUST 仅由服务端附带匹配凭据执行 `tools/call`。

#### Scenario: 模型参数通过验证

- **WHEN** 模型为已授权工具提出符合发现结构的参数对象
- **THEN** 宿主 MUST 携带服务端令牌调用该工具
- **AND** MUST 使用模型提供并经校验的参数而非覆盖为硬编码参数

#### Scenario: 参数错误不出站

- **WHEN** 模型参数缺少必填字段、类型错误、非法 JSON 或超过上限
- **THEN** 本次调用 MUST 显示 `error` 并返回脱敏原因给模型
- **AND** 远端 MUST 未被调用

#### Scenario: 运行期连接失效

- **WHEN** 保存技能时有效的服务器在实际执行前已断开或快照失效
- **THEN** 宿主 MUST 返回该引用的 `denied`
- **AND** MUST NOT 因保存时曾有效而继续调用

### Requirement: 多轮工具消息与终止配额

宿主 MUST 把模型的调用请求与其关联的 `tool` 结果成对回传，允许下一轮基于结果继续选择工具。每问默认 MUST 最多 3 轮工具决策、8 次模型提出的调用尝试及 20 秒工具编排时间；每会话默认 MUST 最多 40 次已预留的远端调用，跨提问与重启累计。上限 MUST 可由服务端配置且禁止非正数；一次返回多个调用 MUST 分别计数，并发提问 MUST 不得绕过会话配额。超限 MUST 停止后续工具执行、以 `denied` 和固定原因体现拒绝，并关闭工具选择后基于已有数据继续生成答案，MUST NOT 因超限使整轮回答直接失败。

#### Scenario: 两步连续调用

- **WHEN** 模型第一轮调用公式提示，收到结果后第二轮调用单位提示
- **THEN** 宿主 MUST 按顺序执行并回传两条关联结果
- **AND** 每次调用 MUST 带可区分的调用标识和轮次

#### Scenario: 轮次或次数耗尽

- **WHEN** 达到配置的轮次、尝试次数、累计远端次数或工具时间上限
- **THEN** 宿主 MUST 不再执行新的远端调用
- **AND** MUST 显示配额拒绝并继续正常的最终流式作答

#### Scenario: 累计配额不可并发绕过

- **WHEN** 同一会话剩一个远端调用额度，同时到达两个提问
- **THEN** 最多一个远端调用 MUST 获得额度
- **AND** 重启 API 后已使用的额度 MUST 不被重置

### Requirement: 工具数据边界与局部失败

工具文本 MUST 作为标注 `tool@server` 来源的数据放在 `tool` 消息中，MUST NOT 进入系统提示或改变宿主权限。远端超时、401、协议错误、`isError=true`、非文本或空结果 MUST 显示 `error` 并以固定、脱敏工具消息回传；单次失败 MUST 不阻断其余检索与最终作答。输入模型前 MUST 限制结果长度并检查已知指令式载荷；命中时 MUST 整条丢弃、替换为固定拒用说明，MUST NOT 部分删除后当成功数据继续使用。所有发给模型/浏览器的错误和摘要 MUST 不含令牌或原始网络诊断。

#### Scenario: 外部工具出错但对话继续

- **WHEN** 工具服务超时或返回 `isError=true`
- **THEN** 调用 MUST 为 `error`，模型 MUST 收到可读的局部失败信息
- **AND** 仍 MUST 能生成最终回答，MUST NOT 把失败记成 `ok`

#### Scenario: 注入载荷整条丢弃

- **WHEN** 工具结果含已知“忽略之前指令”或获取/外发凭据的载荷
- **THEN** 该条文本 MUST 不进入模型、SSE 或成功摘要
- **AND** 调用 MUST 标为 `error`，替换内容 MUST 为固定数据拒用说明

### Requirement: 单次调用审计与教师查询

能够归属本班现存服务器的每次实际调用、参数错误和拒绝 MUST 各留一条审计，至少包含 `tool@server`、服务器名、`ok/error/denied`、用户、会话、提问标识、轮次、调用标识、时间及有界脱敏摘要/原因。缺失、已删除或跨班服务器 MUST 至少出现在本次应答的拒绝清单中，MUST NOT 为落审计而访问其他班级数据。`GET /api/mcp/audit` MUST 仅允许教师按本班范围分页倒序查询，可按服务器和状态筛选。审计预写失败时 MUST 拒绝执行远端调用，但 MUST 不阻断最终回答；审计 MUST NOT 保存令牌、完整提示词或未经过滤的原始结果。

#### Scenario: 三种状态可回溯

- **WHEN** 本班分别发生成功、工具错误和对已断开服务器的调用
- **THEN** 本班教师 MUST 分别查到 `ok`、`error`、`denied` 的记录
- **AND** MUST 能对应到发起用户、会话、提问和轮次

#### Scenario: 审计班级隔离

- **WHEN** 班级 B 教师查询审计或指定班级 A 的服务器筛选
- **THEN** 系统 MUST 不返回班级 A 的调用数据
- **AND** 指定他班服务器 MUST 与不存在一致返回 404

#### Scenario: 审计不可写时不执行动作

- **WHEN** 宿主无法持久化本次调用的审计预记录
- **THEN** MUST 不发远端请求，并在本次工具清单显示失败
- **AND** MUST 继续最终答案生成
