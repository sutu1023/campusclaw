# ai-skills Specification

## Purpose

让教师用一份单一文本文件维护本班技能：空行以上是元数据、空行以下是引导规程；服务端解析后写成可供确定性路由的一条技能，并保留原文以便取回再编辑。

## Requirements

### Requirement: 技能文件格式与解析

技能 MUST 以单一文本文件定义：空行以上为元数据区，空行以下为引导规程。元数据区 MUST 支持 `名称`、`适用条件`、`资料`、`工具`、`启用` 五个键；以 `#` 开头的行与空行在元数据区 MUST 被忽略。系统 MUST 在解析阶段校验：文件不超过 8000 个字符；`名称` 必填且不超过 32 个字符、班内唯一；`适用条件` 必填且不超过 120 个字符；`启用` 必填；空行以下 MUST 有非空正文且不超过 2000 个字符；`资料` 不超过 32 个字符；`工具` MUST 只接受 `knowledge_search`。同一字段重复出现、出现未定义字段、或空行以下缺少正文时 MUST 拒绝提交并返回面向教师的可读错误信息。

#### Scenario: 合法技能文件解析入库

- **WHEN** 教师提交一份字段齐全、正文非空的技能文件
- **THEN** 系统 MUST 解析出名称、适用条件、资料、工具与启用状态并写入 `skills`
- **AND** 空行以下的正文 MUST 作为技能说明保存

#### Scenario: 缺少必填字段被拒绝

- **WHEN** 技能文件缺少 `名称`、`适用条件` 或 `启用`
- **THEN** 系统 MUST 返回 400
- **AND** 错误信息 MUST 能指出缺失的字段

#### Scenario: 重复或未定义字段被拒绝

- **WHEN** 技能文件重复写了同一字段，或出现 `工具` 之外的未定义字段
- **THEN** 系统 MUST 返回 400
- **AND** MUST NOT 写入该技能

#### Scenario: 非法工具名被拒绝

- **WHEN** 技能文件的 `工具` 不是 `knowledge_search`
- **THEN** 系统 MUST 在解析阶段返回 400
- **AND** MUST NOT 写入该技能

#### Scenario: 缺少正文被拒绝

- **WHEN** 技能文件空行以下没有正文
- **THEN** 系统 MUST 返回 400

#### Scenario: 超出长度上限被拒绝

- **WHEN** 文件超过 8000 字符，或名称、适用条件、资料、正文超过各自上限
- **THEN** 系统 MUST 返回 400
- **AND** MUST NOT 写入该技能

#### Scenario: 元数据区忽略注释与空行

- **WHEN** 元数据区含以 `#` 开头的行或空行
- **THEN** 系统 MUST 忽略这些行并正常解析其余字段

### Requirement: 技能原文保留与取回

系统 MUST 保留教师提交的整份技能文件原文（`source_text`），并 MUST 在读取技能时返回该原文，使教师可据此取回再编辑。

#### Scenario: 取回的原文与提交一致

- **WHEN** 教师创建技能后再读取该技能
- **THEN** 返回的原文 MUST 与提交的文件内容一致

### Requirement: 教师增删改查与启停

系统 MUST 允许已登录用户列出本班技能，并 MUST 只允许教师新建、修改与删除本班技能；学生调用写接口 MUST 返回 403。`名称` MUST 在班内唯一；按编号访问他班技能 MUST 返回 404。删除技能时 MUST 同时清除其与智能体的绑定。技能被停用后 MUST NOT 参与路由，即使仍被智能体绑定。

#### Scenario: 学生写技能被拒绝

- **WHEN** 以 student 角色的有效会话调用技能新建、修改或删除接口
- **THEN** 系统 MUST 返回 403
- **AND** `skills` 表 MUST 无新增或变更

#### Scenario: 教师新建与改写

- **WHEN** 教师多次提交合法技能文件
- **THEN** 系统 MUST 分别新增或更新本班技能
- **AND** 每次写入 MUST 保留对应的原文

#### Scenario: 班内技能同名被拒绝

- **WHEN** 教师提交的 `名称` 在本班已存在
- **THEN** 系统 MUST 返回 400

#### Scenario: 删除技能清除绑定

- **WHEN** 教师删除一个已被智能体绑定的技能
- **THEN** 系统 MUST 删除该技能
- **AND** MUST 同时清除指向它的绑定关系

#### Scenario: 停用技能退出路由

- **WHEN** 教师把某技能改为未启用，之后重复同一句提问
- **THEN** 该技能 MUST NOT 再进入候选集
- **AND** 回答行为 MUST 随之改变

#### Scenario: 跨班按编号读取技能为不存在

- **WHEN** 以班级 A 的会话按编号读取班级 B 的技能
- **THEN** 系统 MUST 返回 404
- **AND** MUST NOT 返回该技能的名称、适用条件或正文

### Requirement: 技能资料范围过滤

`资料`（`subject_text`）MUST 作为该技能生效时的检索范围限制：非空时，检索结果 MUST 只保留标题包含该词的材料；为空时 MUST 不做该过滤。

#### Scenario: 资料非空时按标题过滤

- **WHEN** 命中一个 `资料：数学` 的技能并完成检索
- **THEN** 引用列表 MUST 只包含标题含「数学」的材料
- **AND** MUST NOT 包含标题不含该词的材料

### Requirement: 预置技能种子

系统 MUST 在初始化 / 种子阶段为本班预置「解题引导」类技能（至少数学与语文各一条），并 MUST 以幂等种子键（`seed_key`）保证重复执行不产生重复记录；教师自建的技能 MUST NOT 使用种子键。

#### Scenario: 种子可重复执行

- **WHEN** 在已有数据的库上重复执行种子
- **THEN** 预置技能条数 MUST NOT 增加重复记录

#### Scenario: 预置技能可被路由命中

- **WHEN** 提问包含预置技能 `适用条件` 中的词
- **THEN** 该预置技能 MUST 可被该智能体路由命中
- **AND** 其名称含「解题引导」时 MUST 触发不给出最终答案的硬性要求
