# model-gateway Specification

## Purpose

让对话网关与嵌入网关复用同一 API，使演示环境只需配置一套网关地址与密钥即可同时支持向量化与问答。

## Requirements

### Requirement: 对话与嵌入共用网关 API

系统 MUST 在未显式提供对话网关地址或密钥时，回退使用嵌入网关的地址与密钥；对话模型 MUST 由独立配置项指定（默认 `course-chat`）。网关地址与密钥 MUST 仅由服务端读取，MUST NOT 下发浏览器。

#### Scenario: 未配置对话网关时回退

- **WHEN** 仅提供嵌入网关的地址与密钥，未提供对话网关的地址与密钥
- **THEN** 系统 MUST 使用嵌入网关的地址与密钥调用对话接口
- **AND** 在存在依据时问答 MUST 能返回回答

#### Scenario: 显式配置优先

- **WHEN** 显式提供对话网关地址或密钥
- **THEN** 系统 MUST 使用显式配置，而不是回退值

#### Scenario: 对话模型可配置

- **WHEN** 提供对话模型配置项
- **THEN** 调用对话接口时 MUST 使用该模型名

### Requirement: 流式对话补全

对话网关 MUST 支持流式补全调用：服务端 MUST 消费网关返回的增量（如 OpenAI 兼容的 `stream: true` 响应），并把新增文本作为 `delta` 事件转发，MUST NOT 等整段回答生成完毕才产生第一个文本片段。网关地址、密钥与模型 MUST 仍只由服务端读取，MUST NOT 下发浏览器；显式配置优先与回退规则 MUST 与既有要求一致。

#### Scenario: 消费上游增量并转发

- **WHEN** 服务端调用对话网关的流式补全接口
- **THEN** 系统 MUST 在收到每个增量时即可向外转发对应文本
- **AND** MUST NOT 等待完整回答后才转发首个文本片段

#### Scenario: 流式调用沿用网关配置与回退

- **WHEN** 仅配置了嵌入网关地址与密钥，未显式配置对话网关
- **THEN** 流式补全 MUST 仍使用嵌入网关的地址与密钥
- **AND** MUST 使用配置的对话模型

#### Scenario: 网关配置不下发浏览器

- **WHEN** 前端发起或接收流式回答
- **THEN** 响应与脚本中 MUST NOT 出现对话网关地址、密钥或模型凭据

### Requirement: 模型工具声明与结构化调用

服务端调用 OpenAI 兼容对话网关时 MUST 能传入候选工具的名称、说明和参数结构，并读取模型返回的结构化调用列表，包括调用标识、函数名及参数。模型使用的函数名 MUST 可无歧义地映射回完整 `tool@server`，MUST 符合网关函数名约束；两个服务器的同名工具 MUST NOT 发生别名冲突。模型 MUST 不获得 MCP Base URL、令牌或凭据引用。普通无 MCP 问答的请求结构与配置回退规则 MUST 保持兼容。

#### Scenario: 将发现结构交给模型

- **WHEN** 宿主为命中的技能构建工具决策请求
- **THEN** 工具说明和参数结构 MUST 来自批准的发现快照
- **AND** 模型返回的调用标识和参数 MUST 可供宿主逐项处理

#### Scenario: 同名工具可区分

- **WHEN** 两个获准候选在不同服务器上使用同一工具名
- **THEN** 模型函数名 MUST 各自唯一并可映射回正确引用
- **AND** 服务器地址与密钥 MUST 不进入模型请求

### Requirement: 宿主工具消息与最终真流式回答

网关消息 MUST 支持宿主生成的 assistant 工具调用及与 `tool_call_id` 对应的 `tool` 文本结果；每个已处理调用 MUST 有对应结果，包括失败和拒绝。该能力 MUST NOT 放宽客户端/历史消息的可信角色过滤。工具决策结束、失败或达到配额时，宿主 MUST 禁止进一步工具选择并继续使用现有流式补全产生最终正文，MUST NOT 把缓冲好的整段答案拆成假流。网关不支持工具协议或返回非法结构时 MUST 作为工具阶段失败显示，随后尝试不带工具的原有流式路径，MUST NOT 静默假装工具成功。

#### Scenario: 工具结果参与下一轮

- **WHEN** 模型提出调用且宿主获得结果
- **THEN** 下一轮网关请求 MUST 包含相同调用标识关联的 `tool` 消息
- **AND** MUST 能根据该结果再提出另一次调用

#### Scenario: 无工具时保持旧流式路径

- **WHEN** 未命中 MCP 技能
- **THEN** MUST 不发送多余的工具决策请求
- **AND** 现有上游增量转发、配置显式优先及嵌入网关回退 MUST 保持不变

#### Scenario: 网关不支持工具

- **WHEN** 网关拒绝工具请求或返回无法解释的结构化调用
- **THEN** 本次工具阶段 MUST 显示可读失败
- **AND** 宿主 MUST 尝试不带工具的流式作答，不记录伪造的成功审计
